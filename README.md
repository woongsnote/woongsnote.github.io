@woongsnote의 Personal Link Hub입니다. Blog, GitHub, Email로 연결되는 개인 시작 페이지입니다.

## Live Site

https://woongsnote.github.io

## Links

- Blog
- GitHub
- Email

## Stack

- Astro
- TypeScript
- CSS

## Project

- Static site
- No client-side JavaScript
- GitHub Pages deployment

## Development

```sh
npm install
npm run dev
```

## Validation / Build

```sh
npm run check
npm run build
```
